# 📊 Retail Sales Dataset - Exploratory Data Analysis

A complete Exploratory Data Analysis (EDA) project performed on a cleaned retail sales dataset using Python and interactive Plotly visualizations. The project uncovers valuable business insights related to customer behavior, product performance, sales trends, profitability, logistics, and operational efficiency.

---

# 📌 Project Overview

Exploratory Data Analysis (EDA) is one of the most important phases of the data analytics workflow. This project analyzes a cleaned retail sales dataset to identify patterns, trends, and relationships that support data-driven business decision-making.

Interactive visualizations created using Plotly enable dynamic exploration of the data.
